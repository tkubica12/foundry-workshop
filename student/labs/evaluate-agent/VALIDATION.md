# Evaluation lab qualification boundary

The public baseline retains the eight fictional pickup queries, their reference
download, the style rubric and candidate instructions. Content tests check their
agreement with the HTML guide. Browser checks exercise download/copy, text steps,
keyboard navigation, light/dark reading and isolated exports.

The guide deliberately contains no UI screenshots. Menu paths, control labels,
field values and expected results are written directly in each step. Private
rehearsal reports and resource ledgers are not distributed; historical scores
are not guarantees for a new public environment.

Before delivery, follow the guide using the intended attendee identity and
verify dataset upload and preview, saved agent versions, USER input mapping,
judge and evaluator versions, Add run, Compare runs, cluster analysis, trace
access and recovery paths. Keep configuration identical except for the intended
instruction change. Read individual answers; a passing judge can miss factual
errors.

Synthetic generation and automatic trace sampling remain separately gated
extensions. A completed job without readable, verified rows is not a usable
dataset. Do not broaden permissions or network access to bypass a failed
checkpoint. Rehearse the complete elapsed path before accepting the planned
55-minute duration.

Run results and review scope are recorded in `teacher/VALIDATION.md`.
