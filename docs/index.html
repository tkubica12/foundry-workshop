Microsoft Foundry / One-day workshop

Workshop labs

One day. One progressive agent journey. Create a project, build and evaluate an agent, then connect tools and inspect its actions. Follow each lab as an HTML reading guide.

  1. Lab 1: Create a project and deploy models

    20 minutes for the core: create a project in your assigned resource group in Sweden Central, get primary/Luna replies, and submit GLM Flash with custom capacity. Finish pending GLM deployment and hello checks later. Confirm access and quota with your facilitator first.

  2. Lab 2: Build an agent

    30 minutes. Compare model replies and inspect a guardrail. Start only after your facilitator confirms your seat is ready.

  3. Lab 3: Evaluate and improve

    Continue with the agent from Lab 2. Compare a baseline with a deliberate instruction change.

  4. Lab 4: Connect tools

    55 minutes. Curate a toolbox from registered MCP services, attach its endpoint, approve a synthetic assignment and inspect its traces. Confirm tool and telemetry access first.

  5. Lab 5: Ground with knowledge

    45 minutes for the core, plus recovery and discussion. Upload 20 synthetic PDFs, verify a cited answer and compare the same balanced 20 questions. Extend to all 100 after the core.
