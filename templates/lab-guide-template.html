Local exercise / Authoring example

Keep a reproducible learning record

Record one observation, the evidence supporting it and the next check that would reduce uncertainty. Use a modern browser and a local text editor; no account, cloud resource or installation is required.

Preparation / Identify the observation

Start with
what you actually saw.

  1. Record the visible outcome

    Open a local text editor. Write one sentence describing what you observed, without inferring a cause. Use synthetic data only.

Expected result: one observation that another person could check.

Evidence / Identify the gap

Record the gap.
Do not fill it with confidence.

  1. Name the evidence

    Add the source and version that support your observation. If you cannot identify them, write Not recorded.

A result without a version cannot establish what changed. A local note cannot certify that a cloud run occurred.

Expected result: each claim has a source or an explicit gap.

Decision / Save the next check

Leave with
one testable next action.

  1. Save the next action

    Name one check that would address the gap. Save your text file locally. Reopen it and verify your observation, source and next action survived.

If the file is absent, use your editor's Save As command and choose a known local folder. To resume, reopen that file; to reset, create a new record without overwriting the original. Delete only that local file when you no longer need it.

Optional extension: ask a peer to distinguish your observation from your conclusion using only the saved record.

Keep the observation, its evidence and its limit together.

Be precise
about what you know.
